## Sistema para efetuar cálculo de valor venal para Apartamentos com área PI🏡

Para realizar o cálculo é necessário informar os valores abaixo, atentando-se a colocar apenas os separadores de centavos com (.)

Os valores obrigatórios para o cálculo são:

# Prenotação
# Custas
# Emolumentos
# Valor Venal total
# Área do terreno
# Valor territorial
# Área Ideal
# Fração ideal

## O sistema irá preencher:
# Valor Venal do Apartamento + PI
# Valor Venal apenas da PI
# Valor complementar das custas
